# Настройки: функции по выбору

Состояние: этапы 1–6 сделаны, этап 7 — проверка руками по трём режимам. Макеты — холст «PhotoChoice: темы 2.0», раздел «5 · Настройки».
Этапы отмечать здесь (`[x]`), как в `SmartCulling.md`.

## Зачем

Приложение начиналось как перенос кадров из папки в папку. Теперь в нём звёзды, цвета, умный отбор, сравнение, рисование. Окно настроек превратилось в один длинный список (15 настроек и 2 кнопки, 490 строк), а переключатель функций есть только у части из них. Нужно:

1. Дать выбрать, какие функции вообще нужны: перенос по папкам, звёзды, цветовые метки, флаги, умный отбор, инструменты просмотра.
2. Выключенная функция не оставляет следов: ни клавиш, ни подсказок, ни пунктов меню, ни блоков на стартовом экране.
3. Разложить настройки по страницам, а длинные пояснения убрать из основного вида.

Ничего не меняется для тех, кто работает как раньше: по умолчанию включён перенос, остальное как сейчас.

## 2. Модули

Всегда работает (не отключается): сетка и просмотр одного кадра, листание, зум, `F`, `Delete` → корзина, `Z`, копирование и перетаскивание, пары RAW + JPEG, порядок кадров.

| Модуль | Ключ | По умолчанию | Клавиши |
|---|---|---|---|
| Перенос по папкам | `featureTransfer` | вкл | `1`–`9`, свайп вправо и вверх |
| Звёзды | `featureStars` | выкл | `⌥0`–`⌥5` |
| Цветовые метки | `featureColors` | выкл | `⌃0`–`⌃8` |
| Флаги (новое) | `featureFlags` | выкл | `⌥P` оставить, `⌥X` отклонить, `⌥U` снять |
| Умный отбор | `smartAnalysis` (прежний ключ) | вкл | `⌘2`–`⌘4`, `⌥⌘K` |
| Сравнение | `featureCompare` | вкл | `C` |
| Рисование | `featureDrawing` | вкл | `D`, `⌘S`, `⇧⌘C` |
| Сведения о снимке | `featureInfo` | вкл | `I` |

Прежние ключи не переименовываются: данные пользователя лежат в контейнере `VS.PhotoChoice`.

### Что скрывается при выключении

- **Перенос**: карточка «Папки назначения» на старте; папка «Отобранные» не назначается; `1`–`9` и свайпы вправо и вверх ничего не делают; в подсказках нет групп с папками; пункт меню «В первую папку» убран; блок переименования при переносе недоступен. Остаются корзина (`Delete`, свайп влево) и отмена.
- **Звёзды / цвета / флаги**: клавиши не обрабатываются, элементы не рисуются на ячейках сетки, в просмотре и в сравнении, в панели фильтра нет соответствующей секции, а в XMP эта часть не пишется. Данные из `marks.json` не удаляются: включили обратно, и всё на месте.
- **Сравнение**, **рисование**, **сведения**: клавиша не работает, пункт меню и подсказка убраны. Рисование выключается вместе с «Сохранить копию с пометками» и «Копировать с пометками».
- **Умный отбор**: как сейчас (нет разделов «Брак», «Серии», «Люди», анализ не запускается).

### Режимы

Над списком модулей три кнопки. Они только расставляют чекбоксы, отдельно режим не хранится.

| Режим | Перенос | Звёзды | Цвета | Флаги |
|---|---|---|---|---|
| Раскладка по папкам | вкл | выкл | выкл | выкл |
| Только оценки | выкл | вкл | вкл | вкл |
| Всё вместе | вкл | вкл | вкл | вкл |

Если сочетание другое, подсвечивается «Свой набор». Умный отбор и инструменты режимом не трогаются.

## 3. Страницы окна настроек

Окно 760 × 560, слева список страниц, справа содержимое. Выключенный модуль в списке страниц помечен «выкл», его страница доступна, но поля затемнены, а наверху кнопка «Включить».

| Страница | Что на ней |
|---|---|
| Функции | режимы, чекбоксы модулей, у каждого строка пояснения и кнопка «Настроить» |
| Перенос и имена | папка «Отобранные» по умолчанию, переименование при переносе, шаблон имени, разовое переименование всей папки |
| Оценки | звёзды, цвета, флаги: что показывать, как ставить, фильтр, XMP |
| Умный отбор | анализ, строгость, автооткрытие брака, интервал серии, люди и похожесть лиц, MobileCLIP, кэш |
| Просмотр | порядок по времени съёмки, пары RAW + JPEG, палитра в панели сведений |
| Оформление | тема, светлый и тёмный режим |

Правила текста:

- под каждым пунктом одна строка, до 90 знаков;
- длинное пояснение уходит в кнопку «?» (popover) или в сворачиваемый блок «Подробнее»;
- прежние абзацы переносятся туда без потери смысла, прежде всего про ⌃1–⌃8 и Mission Control, XMP и кэш анализа.

## 4. Хранение

Новый файл `Preferences.swift`:

```swift
enum Feature: String, CaseIterable, Identifiable {
    case transfer, stars, colors, flags, compare, drawing, info
    var key: String { "feature" + rawValue.capitalized }
    var defaultOn: Bool { ... }          // transfer, compare, drawing, info: true
    var isOn: Bool { UserDefaults.standard.object(forKey: key) as? Bool ?? defaultOn }
}

enum Pref {                                // остальные ключи, одно место для имён и значений по умолчанию
    static let seriesGap = "seriesGap"
    ...
    static func register()                 // UserDefaults.register(defaults:) на старте
}
```

- `Pref.register()` вызывается в `PhotoChoiceApp.init`. После него все `object(forKey:) as? Bool ?? true` заменяются на `bool(forKey:)`.
- Во view по-прежнему `@AppStorage(Feature.stars.key)`; модельный код читает `Feature.stars.isOn`.
- Меню в `PhotoChoiceApp` реагирует на выключение через `@AppStorage` в самой структуре приложения.
- Миграция (`prefsVersion`, сейчас 1): если `marksEnabled == true`, то `featureStars` и `featureColors` ставятся в `true`. Старый ключ остаётся, но не читается.
- Режим (`WorkMode`) считается из четырёх флагов, не хранится.

Файлы настроек в `PhotoChoice/Settings/` (проект с синхронизируемыми группами, в `pbxproj` ничего добавлять не нужно):

`SettingsShell.swift` (список страниц, переключение), `SettingsComponents.swift` (`SettingsGroup`, `FeatureRow`, `SettingsNote`, «?»), `FeaturesPage.swift`, `TransferPage.swift`, `MarksPage.swift`, `SmartPage.swift`, `ViewPage.swift`, `AppearancePage.swift`. `SettingsView.swift` превращается в тонкую обёртку и позже удаляется. Темы, `PCCheckbox`, `PCButtonStyle` остаются как есть.

## 6. Флаги

- `PhotoMark` получает `flag: Int` (0 нет, 1 оставить, 2 отклонить); `marks.json` читается с `decodeIfPresent`, старые файлы остаются валидными.
- Отмена бесплатно: `UndoStep.marks` уже хранит прежний `PhotoMark` целиком.
- Клавиши `⌥P`, `⌥X`, `⌥U` разбираются по кодам клавиш, как `MarkCommand`; конфликтов нет (`P`, `X` без модификатора заняты рисованием и сравнением, а с `⌥` свободны).
- В ячейке сетки: белый флажок для «оставить», перечёркнутый для «отклонить» (отклонённый кадр чуть приглушён). Фильтр: «Оставлено», «Отклонено», «Без флага».
- XMP: «отклонить» → `xmp:Rating="-1"` (так отмечают Bridge и Lightroom); для «оставить» стандартного поля нет, в файл не пишется.

## 8. Решено

1. Флаги — `⌥P` / `⌥X` / `⌥U`; «отклонить» в XMP — `xmp:Rating="-1"` вместо звёзд в самом XMP (в приложении звёзды остаются). Поле `xmp:Rating` трогается, только если включены звёзды или кадр отклонён.
2. `Delete` (корзина) остаётся во всех режимах.
3. Выбора режима при первом запуске нет: умолчание и страница «Функции».
4. Умный отбор — общий переключатель плюс «Люди».
